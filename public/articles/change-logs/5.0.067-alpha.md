Since the start of OP5, saving/downloading and loading/importing profiles has been glitched in terms of whether it would actually work or fail and most times hasn't been responsive due to the development of adding new functionalities which over time destroyed the feature for so many months. But at last, this long time bug, and the most important feature of this application, is finally under control and repaired. Dynamically too! Means much smaller save files and... also means all previously saved profiles (if any) MUST be manually converted to the new save format to be usable.

## SAVE CHANGES
+ saving will now include the current app version
+ loading in a profile will now clear all previous entries

## BUGS AND FIXES
* fixed living_status having the same id as age

## WARNING
Only text based saving is compatible at this current time. Any box modifications such as disabling, enabling, highlighting, timestamp visibility, or else will not save. Images, profile scheme, legal information bar, page author, and page written date are not yet compatible either with saving or loading. There is also a bug where pasting in large text will cause a loading error unless manually fixing the save file. Type in the text you want to use and you'll be 100% fine but avoid copying and pasting in data for now.
