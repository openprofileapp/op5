OpenProfile now has a public API link! Want to feature specific data values of a profile on your website? Now you can and it will forever update to the latest. We've also updated our Terms of Service to cover API restrictions. Have fun creating!

## APP CHANGES
+ account types will now sync with Discord roles if connected
+ logging in via Discord will now connect your account
+ updated app auto-backup to cover view count data 
+ added public API link "/api/v1/PROFILE_ID" for featuring characters on your own site
+ added terms for API usage
+ updated main URL to from "preview.openprofile.app" to "openprofile.app"
- removed the scheme menu triangle temporarily due to not scheming

## BUGS AND FIXES
* fixed discord registration security issue
* fixed discord registrations allowing "." as part of the handle
* fixed non-discord registered accounts bypassing the author listing format
* fixed account icon incompatibility with light mode
