This update introduces a brand new fully rewritten scheme managing script, revamped UI, scheming documentation, and a few changes to make life easier.

USER INTERFACE CHANGES
+ added icons to the window controls
+ added change-log button (glitched)
+ made tags more roundish and adding padding
+ fixed search bar text not indented
+ rounded the top top right buttons
+ more squared the top left buttons
+ added text to the top left buttons
+ added premium button to redirect to our support page
+ added no wifi indicator (placeholder)
+ added notification dot (placeholder)
+ added notification and inbox count (placeholder)
+ added completion tag to profiles (placeholder)


* fixed highlighting glitch 

SCHEMING MANAGER
+ finalized 3 schemes (Midnight, Coffee, Spooky)
+ rewrote shadowing
+ added scheme accent color
+ tags now relies on scheme accent color 
+ window controls now colors based on accent color
+ reduced the import image icon opacity from 0.35 to 0.1
+ modified element shading values
+ made hyperlinked text match the scheme accent color
+ schemes will now update the application icon if applicable
+ added custom html code option to schemes
+ added back auto-save/load last active scheme
+ seasonal schemes won't active if a custom scheme is enabled 
+ added scheme support for dynamic elements
+ added import scheme option (placeholder)
+ added full documentation to the scheme manager script

ADDITIONAL
+ updated mobile support
