+ added multidate support

You can now input multiple dates in the written box using any format to prevent timestamps from automatically showing up. European format not yet supported.

+ added help text

When editing a text box help text will show up to help you think about the development of your character of if you're unsure of what to put there.

+ en-us and developer translation updated to v5.0.032
+ added opacity for unsupported languages

Languages with outdated translations not supporting newer versions will appear as faded in the translation list.
